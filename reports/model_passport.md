# Паспорт модели

Документ в духе ЛР4 методички: сводная характеристика обученной модели и результат
её валидации.

## Общие сведения

| Поле | Значение |
|---|---|
| Модель | Безусловный DCGAN (генератор + дискриминатор) |
| Назначение | Генерация изображений одежды Fashion-MNIST (моделирование распределения) |
| Датасет | Fashion-MNIST, 60 000 train / 10 000 test, 1×28×28, 10 классов |
| Вход | Латент $z\in\mathbb{R}^{100}$, $z\sim\mathcal{N}(0,I)$ |
| Выход | Изображение $x\in[-1,1]^{1\times28\times28}$ |
| Фреймворк | PyTorch 2.2 (CPU, Intel-Mac) |

## Архитектура и параметры

| Поле | Значение |
|---|---|
| Генератор | ConvTranspose $100\to7\times7\times96\to14\times14\times48\to28\times28\times1$, BatchNorm+ReLU, tanh; 545 329 параметров |
| Дискриминатор | Conv $28\to14\to7\to1$, LeakyReLU(0,2), логит; 79 537 параметров |
| Обучение | Adam ($\beta_1$=0,5, lr $2\cdot10^{-4}$), пакет 256, 18 эпох, сглаживание меток 0,9 |
| Данные обучения | подвыборка 30 000 (бюджет CPU, ~52 с/эпоху) |
| Вспом. классификатор | CNN, точность 0,90 (для оценки генератора) |

## Метрики (базовая модель, 10 000 генераций против теста)

| Метрика | Значение |
|---|---:|
| domain-FID | 39,5 |
| precision / recall | 0,44 / 0,57 |
| JS-дивергенция классов | 0,014 |
| выпавших классов | 0 |
| средняя уверенность классификатора | 0,74 |
| запоминание (медиана ген→train / test→train) | 5,4 / 3,6 (нет запоминания) |

## Ограничения и уязвимости (по результатам валидации)

- **Выпадение мод при дисбалансе.** Удаление 95 % трёх классов роняет recall
  0,57 → 0,35 и поднимает domain-FID до 116,9; per-class FID удалённых классов
  растёт в 1,5–2,5 раза. Precision при этом не падает — общая реалистичность
  маскирует потерю редких классов.
- **Воспроизведение артефактов при отравлении.** При отравлении 20 % одного класса
  триггером 4×4 генератор воспроизводит триггер в 2,1 % генераций (0 % при 5 %);
  общие метрики почти не меняются. В признаках дискриминатора триггер образует
  отдельный кластер.
- **Запоминание.** Не выявлено (генерации дальше от train, чем тестовые объекты).
- **Технические.** Низкое разрешение, один канал, безусловность; ширина/объём
  ограничены бюджетом CPU.

## Результат валидации

Базовая модель **пригодна** как демонстрационный генератор Fashion-MNIST: устойчивое
обучение, отсутствие коллапса и запоминания, приемлемые метрики. Модель
**непригодна** для использования на данных неизвестного/сомнительного происхождения
без дополнительных мер: она уязвима к дисбалансу обучающего набора (теряет редкие
моды) и к отравлению (воспроизводит внедрённый артефакт). Рекомендуемые меры —
балансировка и взвешенное сэмплирование, условная генерация, фильтрация артефактов,
регуляризация дискриминатора, мониторинг покрытия мод и распределения классов,
детекция триггеров.
